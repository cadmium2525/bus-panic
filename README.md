# 限界バス運行！ 〜遅延上等、罰金覚悟の路線バス〜

スマホでもPCでも遊べる、ブラウザ3Dバス運転 × タイムアタック × 経営スコアのバカゲー。
**「急げば儲かる、暴れれば赤字」** —— 架空の街・限界市を走る路線バスの運転手になって、15か所のバス停を時刻表どおりに回り、終点の限界駅を目指します。

- 技術: Three.js（WebGL）/ 素の JavaScript ES Modules / HTML / CSS / Vite
- 公開: GitHub Pages（静的サイト・サーバー不要・開発費0円）
- 1プレイ: 約5〜8分（制限時間 約7分半）

## 遊び方

1. 緑に光る**停留所の枠内で停車**（5km/h 以下）すると乗降開始。1人乗るごとに **運賃 ¥250**。
2. 定刻を過ぎると **10秒ごとに待ち客が1人帰る**（残客数 = max(0, 初期待機人数 − floor(遅延秒数 / 10))）。定刻までに着けば **定時ボーナス ¥500**。
3. コーン・植木鉢・標識・看板・ガードレール・他の車にぶつけると**罰金**（同じ物体は1回だけ計上）。
4. 路地は近道だけど障害物だらけ。安全な大通りか、危険な近道かを選ぶ（ミニマップの黄色い点線は大通り経由のおすすめルート）。
5. 終点に着けばクリア。時間切れなら途中終了。終点に早めに入って3秒停車すると、残りの停留所を通過扱いにして運行を終えられます。

**総合スコア = 運賃収入 ＋ 定時到着ボーナス ＋ 全停留所制覇ボーナス(¥5,000) − 器物破損罰金 − その他ペナルティ** → ランク S / A / B / C / D

| 罰金対象 | 金額 |
| --- | --- |
| コーン・植木鉢 | −¥200 / 個 |
| 道路標識・看板（立て看板・のぼり・工事看板を含む） | −¥1,000 / 個 |
| ガードレール | −¥2,000 / 回 |
| 他車への衝突 | −¥3,000 / 回 |
| 激しい衝突で乗客転倒（その他） | −¥500 |
| R キーで路面へ復帰（その他） | −¥1,000 |
| 急ブレーキ：時速45km以上で強く踏み続ける（その他） | −¥300 |

### やりこみ要素

- **ゴースト**：自己ベストの走りが半透明のバスとして次の運行に現れます（設定で非表示にできます）。
- **実績**：16 種類（全停留所定時・無事故無違反・路地裏マスター・バスでドリフト・ドボン など）。
- **結果のシェア**：リザルト画面から結果画像を保存・共有できます（対応端末は共有シート）。
- 乗客のひとこと、時間が迫ると盛り上がる BGM、タイヤ痕・破片・火花・土煙、衝突時のスローモーション。

## BGM・効果音（かなでる で作成）

BGM・ジングル・効果音はすべて、自作の作曲アプリ「かなでる」（[cadmium2525/mp4mp3](https://github.com/cadmium2525/mp4mp3) の `daw/`）のエンジンで作っています。音源ファイル（`public/audio/`）はビルド済みでコミットしてあるので、ゲームを動かすだけなら作り直す必要はありません。

| ファイル | 内容 |
| --- | --- |
| `audio-src/songs.mjs` | 曲の定義（タイトル「限界バス運行！のテーマ」・走行中「定刻運行」と遅延時に重ねる層・リザルト・ジングル） |
| `audio-src/sfx.mjs` | 効果音の定義（かなでるのプリセット＋層の直接指定）とループ音（エンジン・タイヤのきしみ） |
| `audio-src/build.mjs` | 書き出し：ループの継ぎ目処理、MP3/WAV への変換、低音のチェック、`src/audio/manifest.js` の生成 |
| `audio-src/json/` | 書き出した曲・効果音の JSON（かなでるアプリの「JSON を貼り付け」でそのまま開ける） |

```bash
git clone https://github.com/cadmium2525/mp4mp3 ../mp4mp3   # かなでる のエンジン
npm run audio                                               # 全部作り直す（ffmpeg が必要）
npm run audio -- --only title,coin                          # 一部だけ
```

**低音の扱い**：スマホのスピーカーで聞いても割れたりこもったりしないよう、

- ベースは倍音の多い音色（エレキベース・プラックベース）にして、ベースのトラックに低域カット（50Hz）と 95Hz の削り・900Hz の持ち上げ
- 曲全体に 42Hz の低域カットと 140Hz のローシェルフ（−3dB）、重い効果音には 130〜320Hz の低域カット
- 書き出し時に、かなでるの解析で帯域バランスと「スマホのスピーカーで何 dB 小さく聞こえるか」を測り、低域が中域より大きいものを警告（現状すべて OK）
- ゲーム内でも全体に 35Hz の低域カット、BGM に 120Hz のローシェルフ（−2dB）とリミッター

遅れているとき・残り時間が少ないときは、走行中の曲に「遅延時の層」（刻む弦・アルペジオ・ブラス・パーカッション）がクロスフェードで重なり、同じ曲のまま盛り上がります。

## GitHub Pages で公開する

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
2. `main` ブランチに push すると `.github/workflows/deploy.yml` がテスト・ビルドして公開します（手動実行も可）。
3. `vite.config.js` は `base: './'` なので、`https://<user>.github.io/<repo>/` のようなリポジトリ配下 URL でもそのまま動きます。

## バランス調整

罰金額・客数・時刻・ランク閾値はすべて初期案です。主な調整箇所:

- `src/config.js` … `RULES`（運賃、遅延10秒、定時ボーナス、制限時間、時刻表の想定平均速度 `scheduleSpeed`）、`PENALTY`、`RANKS`、`BUS`（加速・最高速・ステア）、`QUALITY`
- `src/game/stops.js` … 停留所の位置・待機人数・降車人数
- `src/world/map.js` … 道路・路地（近道）・区画

時刻表は「幹線道路だけを通った最短距離 ÷ 想定平均速度 ＋ 停車時間」から自動生成しています。路地の近道を使うと時間を稼げます。

### 動作確認用の URL パラメータ

| パラメータ | 内容 |
| --- | --- |
| `?quality=low\|mid\|high` | 画質を強制 |
| `?autostart` | タイトルを飛ばして開始 |
| `?autopilot` / `?autopilot=fast` / `?autopilot=fastalley` | 自動運転（`alley` を含むと路地も使う） |
| `?startstop=8` | 8番目の停留所の手前から開始 |

## 品質目標と端末対応

- スマホ（iOS Safari / Android Chrome）は横画面推奨。縦画面では「端末を横にしてください」と案内（回転の強制はしない。設定の「全画面にする」で対応端末は横向き固定を試みる）。
- 画質: 低（解像度上限1倍・30fps・影なし）/ 中 / 高（影あり）。「自動」はスマホ=低、PC=中。
- ノッチ・ホームインジケータを避けるセーフエリア対応、ダブルタップ拡大・スクロール抑止、タブ切替で自動ポーズ、音は最初の操作後に開始。
- 自己ベストと設定のみ localStorage に保存。
