# 限界バス運行！ 〜遅延上等、罰金覚悟の路線バス〜

スマホでもPCでも遊べる、ブラウザ3Dバス運転 × タイムアタック × 経営スコアのバカゲー。
**「急げば儲かる、暴れれば赤字」** —— 架空の街・限界市を走る路線バスの運転手になって、15か所のバス停を時刻表どおりに回り、終点の限界駅を目指します。

- 技術: Three.js（WebGL）/ 素の JavaScript ES Modules / HTML / CSS / Vite
- 公開: GitHub Pages（静的サイト・サーバー不要・開発費0円）
- 1プレイ: 約5〜8分（制限時間 約7分半）

## 遊び方

1. 緑に光る**停留所の枠内で止まる**と乗降開始。1人乗るごとに **運賃 ¥250**。
2. 定刻を過ぎると **10秒ごとに待ち客が1人帰る**（残客数 = max(0, 初期待機人数 − floor(遅延秒数 / 10))）。定刻から 5 秒以内に着けば **定時ボーナス**。定時到着が続くと**定時コンボ**で ¥500 → ¥750 → ¥1,000 …（上限 ¥2,000）と増え、遅れると途切れます。
3. **ピタ止め**：光の柱の真下（白い枠。標柱が進行方向の前寄りに立っている）にぴったり止めると「ピタッ！」+¥500／「ナイス停車」+¥250／「まあまあ」+¥100。止まった位置で判定し、外れたときは「2.4m 手前」のように教えてくれます。停留所の手前 26m から画面下にガイドが出て、カメラも少し高くなります。
4. コーン・植木鉢・標識・看板・ガードレール・他の車にぶつけると**罰金**（同じ物体は1回だけ計上）。
5. 路地は近道だけど障害物だらけ。安全な大通りか、危険な近道かを選ぶ（ミニマップの黄色い点線は大通り経由のおすすめルート）。
6. 終点に着けばクリア。時間切れなら途中終了。終点に早めに入って3秒停車すると、残りの停留所を通過扱いにして運行を終えられます。

**総合スコア = 運賃収入 ＋ 定時ボーナス（コンボ）＋ 運転技術ボーナス（ピタ止め・ライバルに勝つ）＋ 急ぎ客のチップ ＋ 全停留所制覇ボーナス(¥5,000) − 器物破損罰金 − その他ペナルティ** → ランク S / A / B / C / D

### 運行中のハプニング

- **工事の通行止め**：毎回どこかの道がバリケードで塞がれています（ミニマップの ✕）。おすすめルートは自動で回り道を示します。全停留所へ必ず行けるように選んでいます。
- **急ぎの客**：途中の停留所で乗ってきて「〇〇まで〇秒以内に！」。間に合えばチップ ¥2,000。
- **ライバル会社「ギリギリ交通」**：発車すると後ろから現れ、2 つ先の停留所の客を狙います。先に着けば +¥1,000、負けると待ち客の半分を横取りされます。体当たりで邪魔もできます。
- **踏切**：街の南を電車が走っています。カンカン鳴ったら止まって待つこと。遮断機を突破すると −¥2,000、電車に当たると大惨事。

### モード

- **通常運行**：上のルールで 15 停留所を回る基本のモード。
- **日替わりチャレンジ**：日付ごとに「通勤ラッシュ（待ち客 1.5 倍）」「罰金2倍デー」「踏切地獄」「ブレーキ不調」「ターボ搭載」などの条件が 2 つ付き、通行止めや急ぎの客の配置も全員同じ。自己ベストは日ごとに記録。
- **暴走モード**：2 分間、乗客なしで街を壊しまくるモード。2.5 秒以内に**違う種類の物**を壊すとコンボが伸びる（3 コンボ ×1.5、7 コンボ ×2、12 コンボ ×3。同じ種類ばかりだとコンボは伸びない）。

| 罰金対象 | 金額 |
| --- | --- |
| コーン・植木鉢 | −¥200 / 個 |
| 道路標識・看板（立て看板・のぼり・工事看板を含む） | −¥1,000 / 個 |
| ガードレール | −¥2,000 / 回 |
| 他車への衝突 | −¥3,000 / 回 |
| 激しい衝突で乗客転倒（その他） | −¥500 |
| R キーで路面へ復帰（その他） | −¥1,000 |
| 急ブレーキ：時速50km以上で強く踏み続ける（その他。最初の 2 回は注意だけ） | −¥300 |
| 踏切が鳴っているのに遮断機を突破（その他） | −¥2,000 |

### やりこみ要素

- **ゴースト**：自己ベストの走りが半透明のバスとして次の運行に現れます（設定で非表示にできます）。
- **実績**：22 種類（全停留所定時・無事故無違反・定時コンボ 10・ピタ止め職人・ライバル撃破・怪獣バス・路地裏マスター・バスでドリフト・ドボン など）。
- **結果のシェア**：「𝕏 に投稿」で、ランク・停留所ごとの結果（🟩定時 🟨遅延）・ゲームの URL を入れた投稿画面を開けます。「結果を画像でシェア」はゲーム画面入りの画像を保存・共有（対応端末は共有シート）。URL を貼ると X にはカード画像（`public/og.jpg`）が出ます。
- 乗客のひとこと、時間が迫ると盛り上がる BGM、タイヤ痕・破片・火花・土煙、衝突時のスローモーション。

## BGM・効果音（かなでる で作成）

BGM・ジングル・効果音はすべて、自作の作曲アプリ「かなでる」（[cadmium2525/mp4mp3](https://github.com/cadmium2525/mp4mp3) の `daw/`）のエンジンで作っています。音源ファイル（`public/audio/`）はビルド済みでコミットしてあるので、ゲームを動かすだけなら作り直す必要はありません。

| ファイル | 内容 |
| --- | --- |
| `audio-src/songs.mjs` | 曲の定義（タイトル「限界バス運行！のテーマ」・走行中「定刻運行」と遅延時に重ねる層・リザルト・ジングル） |
| `audio-src/sfx.mjs` | 効果音の定義（かなでるのプリセット＋層の直接指定）とループ音（エンジン・タイヤのきしみ・踏切の警報音・電車の走行音） |
| `audio-src/build.mjs` | 書き出し：ループの継ぎ目処理、MP3/WAV への変換、低音のチェック、`src/audio/manifest.js` の生成 |
| `audio-src/json/` | 書き出した曲・効果音の JSON（かなでるアプリの「JSON を貼り付け」でそのまま開ける） |

```bash
git clone https://github.com/cadmium2525/mp4mp3 ../mp4mp3   # かなでる のエンジン
npm run audio                                               # 全部作り直す（ffmpeg が必要）
npm run audio -- --only title,coin                          # 一部だけ
```

**低音の扱い**：スマホのスピーカーで聞いても割れたりこもったりしないよう、

- ベースは倍音の多い音色（エレキベース・プラックベース）にして、ベースのトラックに低域カット（50Hz）と 95Hz の削り・900Hz の持ち上げ
- 曲全体に 42Hz の低域カットと 140Hz のローシェルフ（−3dB）、重い効果音には 130〜320Hz の低域カット
- 書き出し時に、かなでるの解析で帯域バランスと「スマホのスピーカーで何 dB 小さく聞こえるか」を測り、低域が中域より大きいものを警告（現状すべて OK）
- ゲーム内でも全体に 35Hz の低域カット、BGM に 120Hz のローシェルフ（−2dB）とリミッター

遅れているとき・残り時間が少ないときは、走行中の曲に「遅延時の層」（刻む弦・アルペジオ・ブラス・パーカッション）がクロスフェードで重なり、同じ曲のまま盛り上がります。

## PV（紹介動画）の作り方

X 用の PV（16:9・約30秒）は、ゲームの映像を撮影して、自作の動画エディタ「つなぐ」（[cadmium2525/mp4mp3](https://github.com/cadmium2525/mp4mp3) の `editor/`）で組み立てています。

```bash
npm run build && npx vite preview --port 4173 &   # ゲームを起動
node pv/capture.cjs              # 見せ場を 1 コマずつ撮影（URL に ?capture を付けたコマ送りモード）→ pv/build/media
node pv/make.mjs                 # 「つなぐ」のプロジェクト JSON（pv/build/pv.json）を作る
node ../mp4mp3/editor/tools/render.mjs pv/build/pv.json pv/build/media pv/build/genkai-bus-pv.mp4
```

- 撮影モードでは、ページ内の時計（タイマー・アニメーション）もゲームのコマ送りに合わせるので、罰金表示や吹き出しも実際の速さで写ります。
- 撮影中に鳴った効果音の時刻を記録し、PV の効果音をその瞬間に合わせています。
- BGM はゲームのテーマ曲を PV 用に編曲（衝突の瞬間に曲が始まり、カットは小節の頭）。

## GitHub Pages で公開する

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
2. `main` ブランチに push すると `.github/workflows/deploy.yml` がテスト・ビルドして公開します（手動実行も可）。
3. シェア文と OGP の URL は `https://cadmium2525.github.io/bus-panic/` を前提にしています。別の場所で公開するときは `src/config.js` の `SITE_URL` と `index.html` の `og:` / `twitter:` タグを書き換えてください。
4. `vite.config.js` は `base: './'` なので、`https://<user>.github.io/<repo>/` のようなリポジトリ配下 URL でもそのまま動きます。

## バランス調整

罰金額・客数・時刻・ランク閾値はすべて初期案です。主な調整箇所:

- `src/config.js` … `RULES`（運賃、遅延10秒、定時コンボ、ピタ止め、チップ、踏切、制限時間、時刻表の想定平均速度 `scheduleSpeed`）、`PENALTY`、`RANKS`、`RAMPAGE`（暴走モードの時間・ランク）、`BUS`（加速・最高速・ステア）、`QUALITY`
- `src/game/modes.js` … ハプニングの数（通行止め・急ぎの客・ライバル）、電車の間隔、日替わりの条件
- `src/game/stops.js` … 停留所の位置・待機人数・降車人数
- `src/world/map.js` … 道路・路地（近道）・区画

時刻表は「幹線道路だけを通った最短距離 ÷ 想定平均速度 ＋ 停車時間」から自動生成しています。路地の近道を使うと時間を稼げます。

### 動作確認用の URL パラメータ

| パラメータ | 内容 |
| --- | --- |
| `?quality=low\|mid\|high` | 画質を強制 |
| `?autostart` | タイトルを飛ばして開始 |
| `?mode=daily\|rampage` | `?autostart` と一緒に使い、日替わり・暴走モードで開始 |
| `?autopilot` / `?autopilot=fast` / `?autopilot=fastalley` | 自動運転（`alley` を含むと路地も使う、`wild` を含むと踏切で止まらない） |
| `?timescale=4` | ゲーム内時間を 4 倍速で進める |
| `?startstop=8` | 8番目の停留所の手前から開始 |

## 品質目標と端末対応

- スマホ（iOS Safari / Android Chrome）は横画面推奨。縦画面では「端末を横にしてください」と案内（回転の強制はしない。設定の「全画面にする」で対応端末は横向き固定を試みる）。
- 画質: 低（解像度上限1倍・30fps・影なし）/ 中 / 高（影あり）。「自動」はスマホ=低、PC=中。
- ノッチ・ホームインジケータを避けるセーフエリア対応、ダブルタップ拡大・スクロール抑止、タブ切替で自動ポーズ、音は最初の操作後に開始。
- 自己ベストと設定のみ localStorage に保存。
